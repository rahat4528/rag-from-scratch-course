# Known Issues in Cloned Upstream Repository (`langchain-ai/rag-from-scratch`)

All original cloned files at commit `1fdb7d0e4f1d3e731c8397332452715512f18667` are intentionally preserved **byte-for-byte untouched** (except the single link added to `README.md`). While inspecting the upstream notebooks without modifying them, the following outdated patterns and compatibility notes were documented:

| File | Observation / Outdated API | Impact on Modern Python / LangChain 1.x | Course Resolution in `course/` |
|---|---|---|---|
| All 5 root notebooks (`rag_from_scratch_*.ipynb`) | Use `from langchain import hub`, `from langchain.text_splitter import ...`, `from langchain.prompts import ...`, `from langchain.load import dumps, loads`, `from langchain.storage import InMemoryByteStore` | Legacy LangChain v0.1/v0.2 top-level namespace shims removed or moved in LangChain `1.x`; `langchain-community` triggers sunset deprecation warnings | `course/` imports directly from `langchain`, `langchain_core`, `langchain_text_splitters`, `langgraph`, native `pypdf`, and `BeautifulSoup` with zero deprecation warnings |
| `rag_from_scratch_10_and_11.ipynb` | Imports `from langchain_core.pydantic_v1 import BaseModel, Field` and `YoutubeLoader` | `pydantic_v1` compatibility layer deprecated/removed in modern Pydantic v2 environments; `pytube` frequently breaks against YouTube changes | `course/` uses native Pydantic v2 `from pydantic import BaseModel, Field` cleanly |
| `rag_from_scratch_12_to_14.ipynb` | Installs `! pip install -U ragatouille` for ColBERT late interaction | `ragatouille` has native C++/CUDA compilation issues on Windows & Python 3.13 | `course/notebooks/10_advanced_indexing.ipynb` implements pure-Python/PyTorch conceptual + token-level MaxSim ColBERT late-interaction demo cleanly |
| `rag_from_scratch_15_to_18.ipynb` | Requires paid `Cohere` API via `ContextualCompressionRetriever` & `CohereRerank` | Requires paid Cohere key; fails completely without one | `course/notebooks/11_reranking_and_compression.ipynb` uses free local `sentence-transformers` `CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')` and documents hosted Cohere optionally |
| All 5 root notebooks | Require active `OPENAI_API_KEY` and use `chromadb` | Beginners cannot run notebooks without paid API keys; `chromadb` Rust/native extensions can crash on newer Python/Windows combos | `course/` supports `RAG_PROVIDER` switching across `openai`, `anthropic`, `ollama`, and `offline_demo` code-path verification, plus `InMemoryVectorStore` with pure JSON persistence |
| Root repository | No `LICENSE` file or `requirements.txt` in base commit | Learners lack pinned reproducible installs; upstream attribution notes no license file was shipped | Documented cleanly in `course/README.md` with link back to upstream repo; pinned reproducible `course/requirements.txt` provided |
